\section{Неравенства}

Для любых $a, b \in \R$ верны неравенства:
\begin{description}
    \item[вырожденного треугольника:] $|a + b| \le |a| + |b|$
    \item[сравнения модулей:] $||a| - |b|| \le |a - b|$
\end{description}

Для любых неотрицательных $x_1, x_2, \dots, x_n$
их среднее арифметическое не меньше среднего геометрического:
\[
    \frac{x_1 + x_2 + \cdots + x_n}{n} \ge \sqrt[n]{x_1 \cdot x_2 \cdots x_n}
\]
причем равенство достигается тогда и только тогда, когда $x_1 = x_2 = \cdots = x_n$.

В частности:
\[
    \frac{x_1 + x_2}{2} \ge \sqrt{x_1 \cdot x_2}
\]

\begin{theorem}{Неравенство Коши--Буняковского}{}
    Для любых действительных чисел $x_1, \dots, x_n$ и $y_1, \dots, y_n$ выполнено:
    \[
        (x_1 y_1 + \cdots + x_n y_n)^2 \le (x_1^2 + \cdots + x_n^2) \cdot (y_1^2 + \cdots + y_n^2)
    \]
\end{theorem}
